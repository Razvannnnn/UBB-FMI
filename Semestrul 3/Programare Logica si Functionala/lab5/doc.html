Documentație Lisp

CAR

Extrage primul element dintr-o listă.

(car '(rose violet daisy buttercup)) ;; => rose

CDR

Returnează restul listei, în afara de primul element.

(cdr '(rose violet daisy buttercup)) ;; => (violet daisy buttercup)

CONS

Adaugă un element la începutul unei liste.

(cons 'pine '(fir oak maple)) ;; => (pine fir oak maple)
(cons 'buttercup ())          ;; => (buttercup)

LENGTH

Returnează lungimea unei liste.

(length '(daisy buttercup)) ;; => 2

NTHCDR

Face cdr de mai multe ori.

(cdr (cdr '(pine fir oak maple))) ;; => (oak maple)
(nthcdr 2 '(pine fir oak maple)) ;; => (oak maple)

SETQ

Setează o variabilă către o listă.

(setq animals '(giraffe antelope tiger lion)) 
;; => animals: (giraffe antelope tiger lion)

SETCAR

Setează primul element la o valoare dată.

(setcar animals 'hippopotamus) 
;; => animals: (hippopotamus antelope tiger lion)

SETCDR

Setează restul listei.

(setq domesticated-animals '(horse cow sheep goat))
(setcdr domesticated-animals '(cat dog)) 
;; => domesticated-animals: (horse cat dog)

ATOM

Un element indivizibil - numere, simboluri sau caractere unice.

'(this list includes "text between quotation marks.")
;; Atom: "text between quotation marks."

CONCAT

Concatenează două stringuri.

(concat "abc" "def") ;; => "abcdef"

SUBSTRING

Extrage un substring specificat de pozițiile stânga și dreapta.

(substring "The quick brown fox jumped." 16 19) ;; => "fox"

LET

Definește variabile locale.

(let ((zebra 'stripes)
      (tiger 'fierce))
  (message "One kind of animal has %s and another is %s." zebra tiger))
;; => "One kind of animal has stripes and another is fierce."

IF

Execută o acțiune dacă testul este adevărat.

(if (> 5 4)
    (message "The value 5 is greater than 4"))

IF-ELSE

Execută o acțiune diferită dacă testul este fals.

(if (> 5 4)
    (message "The value 5 is greater than 4")
  (message "On else"))

NIL

Are următoarele sensuri:

  • Listă goală
  • Fals (în condiții de tip if)
