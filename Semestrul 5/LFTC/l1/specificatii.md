# Specificare mlp

## Tipuri de date

- tipuri simple: *int* / *float*
- tip definit de utilizator cu 2 campuri : *x* real, *y* real

## Identificatori si constante

- **identificatorii** incep cu litera [azAZ] si nu pot incepe cu [_]
- **constantele** sunt doar cu majuscule , numai mult de **10** caractere , si sunt prefixate cu const

## Instructiuni

- **atribuire** : *id = expresie*
- **intrare/iesire** : *read_int()*, *read_real()*, *print()*
- **conditii** : *if(cond) { ... } else { ... }*
- **ciclu** : *while (cond) { ... }*

## Expresii

- **operatii aritmetice** : *+ - * /*
- **comparatori** : *== != < <= > >=*
